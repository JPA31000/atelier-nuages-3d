Exporter

À savoir sur l'export .rcp (ReCap)

Un vrai fichier ReCap (.rcp + dossier .rcs) est un index propriétaire Autodesk : seul ReCap peut l'écrire. Aucune application web ne le peut.

Le « paquet .rcp » produit ici est une archive ZIP contenant un manifeste de projet (.rcp, texte XML), les scans en LAS, les panoramiques et un fichier stations.csv, plus un README_RCP.txt.

Pour obtenir l'index natif : ouvrir ReCap Pro → nouveau projet → ajouter les LAS → Indexer → insérer le .rcp dans Revit.

Prise en main

  1. Importer : glissez vos fichiers (LAS, LAZ, E57, PLY, XYZ/PTS) et, si besoin, vos panoramiques JPG/PNG.
  2. Naviguer : clic gauche = tourner, clic droit = déplacer, molette = zoom, double-clic = recentrer.
  3. Stations : cliquez une icône 360 dans la scène pour voir le panoramique ; cliquez une autre station pour y aller.
  4. Mesurer : onglet Mesure → deux clics, en 3D ou dans le panoramique.
  5. Assembler : onglet Recalage → pré-alignement manuel, puis ICP.
  6. Nettoyer puis Exporter en LAS, LAZ, PLY, XYZ ou paquet .rcp.

E57 « structuré » ou « non structuré » ?

Structuré : plusieurs scans avec leur position de station (et souvent une grille ligne/colonne et des panoramiques). Non structuré : un nuage global, sans station. L'application l'indique à l'import.

Confidentialité
